# 架构决策记录（ADR）

## 写作规范

- 用 `template.md` 新建，正文中文。
- 记录**决策与理由**，不写操作手册；操作步骤属于 README 或代码注释。
- 已接受的 ADR 正文视为历史记录，不做改写；需要推翻时新增一条，状态写「已被 NNNN 取代」，并在被取代那条顶部加同样的反向标注。
