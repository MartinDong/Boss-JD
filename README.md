# BOSS岗位提取

在 Chrome、Edge、夸克里读取 **当前已经打开** 的 BOSS直聘岗位详情，复制或下载职位内容。

只处理这种地址：`https://www.zhipin.com/job_detail/….html`

插件不会自动翻页，也不会替你通过安全验证。页面如果停在「安全验证」或「请稍候」，先在网页里手动完成，等职位正文出来再提取。

## 安装

1. 打开扩展管理页  
   Chrome：`chrome://extensions`  
   Edge：`edge://extensions`  
   夸克：设置里的扩展管理（地址一般是 `quark://extensions`）
2. 打开「开发者模式」。
3. 选择「加载已解压的扩展程序」，选中本目录（里面要有 `manifest.json`）。
4. 打开一条岗位详情。页面右侧有「岗位」竖条，点它会把网页向左让开。侧边栏默认更宽，左缘可以拖动，双击恢复默认宽度。打开后先显示收藏列表，点开一条可以看到公司名称、位置、距我和完整职位描述。

## 能提取的内容

职位名称、薪资、地点、经验、学历、标签、职位描述、公司、行业、融资、规模、招聘者、工作地址、页面链接。

职位描述用页面可见文本读取，避开隐藏的水印字。薪资如果被网页用自定义字体加密，会提示你直接看页面上的数字。

「收藏」会把提取结果和原始岗位链接写入浏览器里的本地数据库（IndexedDB，库名 `boss-jd`）。同一岗位重复收藏会更新内容，并保留第一次收藏时间。以前用插件临时保存的记录，会在第一次打开时自动迁入这个数据库。

插件弹窗可以导出最近收藏。点「打开收藏库」可以搜索、打开原岗位、删除或清空。数据只在本机这个浏览器配置里，不会上传。
