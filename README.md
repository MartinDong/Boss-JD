# BOSS岗位提取

在 Chrome、Edge、夸克里读取 **当前已经打开** 的 BOSS直聘岗位详情，复制或下载职位内容。

只处理这种地址：`https://www.zhipin.com/job_detail/….html`

插件不会自动翻页，也不会替你通过安全验证。页面如果停在「安全验证」或「请稍候」，先在网页里手动完成，等职位正文出来再提取。

## 安装

1. 打开扩展管理页  
   Chrome：`chrome://extensions`  
   Edge：`edge://extensions`  
   夸克：设置里的扩展管理（地址一般是 `quark://extensions`）
2. 打开「开发者模式」。
3. 选择「加载已解压的扩展程序」，选中本目录（里面要有 `manifest.json`）。
4. 打开一条岗位详情。页面右侧有「岗位」竖条，点它会把网页向左让开。侧边栏默认更宽，左缘可以拖动，双击恢复默认宽度。打开后先显示收藏列表，点开一条可以看到公司名称、位置、距我和完整职位描述。

## 能提取的内容

职位名称、薪资、地点、经验、学历、标签、职位描述、公司、行业、融资、规模、招聘者、工作地址、页面链接。

职位描述用页面可见文本读取，避开隐藏的水印字。薪资如果被网页用自定义字体加密，会提示你直接看页面上的数字。

「收藏」会把提取结果和原始岗位链接写入浏览器里的本地数据库（IndexedDB，库名 `boss-jd`）。同一岗位重复收藏会更新内容，并保留第一次收藏时间。以前用插件临时保存的记录，会在第一次打开时自动迁入这个数据库。

插件弹窗可以导出最近收藏。点「打开收藏库」可以搜索、打开原岗位、删除或清空。数据只在本机这个浏览器配置里，不会上传。

## 简历和填写

弹窗里的「简历和模型」会打开配置页。可以上传多份 txt、md、pdf、docx，也可以直接粘贴正文。其中一份标为默认。

在已经打开的招聘页面点「填写当前页面」，插件会读取这一页的空表单，用默认简历填写，并把简历文件放进页面上的上传框。BOSS 岗位页右侧的「简历」也能做同样的事。

填写不会点击提交，也不会处理安全验证。性别、民族、宗教、残疾、政治面貌这类选项会留空，等你自己决定。

模型要在配置页自己填写接口地址、模型名称和密钥。这三项只保存在浏览器扩展存储里，插件目录中没有默认密钥。保存时浏览器会询问是否允许访问该地址。没有配置模型时，仍会尝试填写简历里能直接认出的姓名、电话、邮箱和学历。

## 求职建议

弹窗或岗位页右上角的「建议」会打开单独的页面。先填写目标职位和必须条件，收藏过的岗位会出现在右侧。可以生成四类结果：岗位推荐、简历修改、投递建议、面试准备。

生成前会先按城市、职位和关键词筛出最多 6 条收藏，再分两步调用你配置的模型：先做匹配分析，再写具体建议。建议保存在本机，下次可直接查看。插件不会自动打招呼或自动投递。没有写进简历的经历不会被编成优势。

## 找岗位和面试

收藏展开后可以记录投递状态（已投、约面、终面、挂了、拿offer）、日期和一句话备注，列表顶部能按状态筛选。在别的网站看到合适的岗位，点「导入岗位」把公司、职位和正文贴进来，和 BOSS 收藏一起参与对比和建议。

建议页会把这些岗位的要求拆成必备项和加分项，逐条对照所选简历，给出满足情况和依据，不出分数。右侧的「面试复盘」记录每次面试的岗位、被问的问题、结果、对方原话反馈、薪资阶段和下次要改的一点。生成建议时会带上最近 3 条结局（面试复盘优先，不够用挂了的投递补），并在结果里列出参考了哪些历史。挂过的岗位只会被标注，不会被自动排除。
